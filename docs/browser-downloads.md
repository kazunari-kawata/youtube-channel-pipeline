# ブラウザ経由の素材の取得（fbi.gov など、クラウドから届かないサイト）

fbi.gov、vault.fbi.gov、usmarshals.gov、floridamemory.com は、クラウドと Windows の作業用シェルからの取得を拒む（403 や確認の画面）。
ユーザーの Windows の Chrome（Claude in Chrome）なら開ける。2026-11-28 の 006 で手順を決めた。

## 一度だけの設定（ユーザー）

1. Chrome の設定 →「ダウンロード」→「ダウンロード前に各ファイルの保存場所を確認する」をオフ
2. Chrome の設定 →「プライバシーとセキュリティ」→「サイトの設定」→「その他の権限」→「自動ダウンロード」に、
   `www.fbi.gov`、`www.usmarshals.gov`（ほかに使うサイトも）を「許可」で足す。これがないと、2つ目からのダウンロードが止まる
3. Claude のデスクトップアプリで、会話に Windows の「ダウンロード」フォルダを追加する（「+」→「フォルダを追加」）。
   アクセスの確認の画面が出たら許可する（2026-11-28 は確認の画面が時間切れで2回閉じた）

## 取り方（Claude）

1. 保存の前に、ファイル名・取得元・大きさをユーザーに伝えて許可をもらう（CLAUDE.md、会話の安全の決まり）
2. Chrome で公式ページを開き、`img` タグから元画像の URL を取る。fbi.gov の画像は `/image-repository/<名前>/@@images/image` が元の大きさ
   （`/@@images/image/large` は縮小版）
3. ページの中で `fetch` → `Blob` → `<a download="<回>_<元の名前>">` でダウンロード（回の番号を頭に付けて、どの回の素材か分かるようにする）
4. ダウンロードから `episodes/<回>/build/materials/` の台帳の `file` の場所へ移す（作業用シェルで。ダウンロードのフォルダがつながっていなければ、
   ユーザーに PowerShell の `Copy-Item` を頼む）
5. 台帳の note に、取得日と元の URL を書く

## うまくいかなかったこと

- 2026-11-28：006 の11ファイルをこの手順の3で保存したが、ダウンロードに届いていなかった（上の設定1・2がなかった可能性）。
  保存したタブを閉じると、Chrome の「複数のファイルをダウンロードしようとしています」の確認も消える
- 画面の写し（スクリーンショット）は、ページ全体の記録（手配ページの載り方など）に使う。写真の元画像の代わりにはしない（解像度が足りない）
