# ショートの公開後の数字（F-064）

公開したショートの数字を1本1行で残し、次のショートの作りに生かす。決まりは CLAUDE.md の「ショート動画」。

- **視聴された**：Studio のリーチの「視聴された（vs スワイプ）」。フィードで冒頭を見た人のうち、スワイプせずに見た割合。最初の1〜3秒の出来を見る数字
- **平均再生率**：平均視聴時間 ÷ 長さ。100% を超えるのは繰り返し見られたとき
- **維持率の落ち込み**：維持率の曲線が急に下がる秒。公開から2〜3日後（API に出てから）に vidIQ（`vidiq_channel_analytics`、`report: audience_retention`、`filters: video==ID`）で取り、
  その秒の絵と字幕（`remotion/public/shorts/<id>/data.json` の `shots`・`captions`）と並べて書く。声が途切れていないか、テンポが落ちていないかを見る
- 目安（2026-11-28 に YouTube Studio の助言として共有されたもの）：視聴された 70〜80%以上、平均再生率 80〜100%以上
