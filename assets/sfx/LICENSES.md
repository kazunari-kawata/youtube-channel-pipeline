# 効果音の記録

使ってよいのは、**商用（収益化したYouTube）で使えて、帰属表示（クレジット）がいらない音だけ**（F-012）。
音を追加したら、必ずこの表に1行足す。ここに無い音は使わない。ファイル名は `config/sfx.yaml` の名前_番号.wav（例 paper_1.wav）。

## 取ってよい所（2026-11-25 に規約を確認）

| サイト | 条件 | 注意 |
| --- | --- | --- |
| YouTube オーディオライブラリ（効果音タブ） | 収益化できる。Content ID で申し立てを受けない | YouTube Studio で開く。開く前にログイン中のチャンネルが Syncage 用か確かめる（F-007） |
| Mixkit | 商用・YouTube 可、クレジット不要 | 音だけを再配布しない |
| Pixabay（効果音） | 商用可、クレジット不要 | 誰でも投稿できるので、まれに Content ID の申し立てがありうる。投稿者が録った音か説明を見る |
| Freesound | **CC0 の音だけ**（検索でライセンスを CC0 に絞る） | CC BY は帰属表示が要るので使わない。CC BY-NC は商用不可。取得時のライセンス画面を保存する |
| Sonniss GDC Game Audio Bundle | 商用可、クレジット不要、作品数の制限なし | 数GB〜数十GBの一括ダウンロード。AIの学習には使えない（2024年以降の版） |
| 効果音ラボ | 商用可・クレジット不要と紹介されている | **使う前に公式の規約を原文で確認してから**（2026-11-25 時点で原文は未確認） |

## 使わない所

- OtoLogic（CC BY 4.0。クレジット必須）
- ZapSplat の無料版（クレジット必須。音を第三者へ譲れない＝チャンネル売却の妨げになりうる）
- BBC Sound Effects（RemArc。商用不可）
- Epidemic Sound など定額制（契約が切れると使えなくなる。売却時に引き継げない）
- AI で生成した効果音（規約が変わりやすく、権利の説明が難しい。使うならユーザーと相談してから）
