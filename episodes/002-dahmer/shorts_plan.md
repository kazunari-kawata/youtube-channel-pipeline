# 002 ダーマー ショート動画の案（2026-11-27、ユーザーOK待ち）

## 形式

- 1080x1920（9:16）、30fps。作業座標は 720x1280 を1.5倍（本編の 1280x720×1.5 と同じ考え方）
- 長さは3分まで（縦か正方形で3分以内はショートになる）。1分を超えるショートは Content ID の申し立てがあると全世界で見られなくなる。
  BGMはオーディオライブラリの曲なので申し立ては来ない想定。それでも最初の数本は60秒以内にする
- 1フレーム目＝サムネイル。カスタムのサムネイル画像は YouTube パートナープログラム（YPP）の参加者だけなので、
  いまはスマホのアプリで動画のフレームを選ぶ（パソコンの Studio は候補3枚から選ぶだけ）。1フレーム目を約0.8秒見せ、声は0秒から始める
- 本編へ：Studio の「関連動画」で本編につなぐ。最後は問いで終え、1.5秒だけ「本編はこの下のリンクから」を出す

## 画面の作り

- 縦に作り直す（16:9 の真ん中を切り抜く、上下をぼかして16:9を置く、はしない）
  - 資料・写真：横幅いっぱいに。逮捕時の写真は縦長なので縦の画面に合う。日本語の説明（F-020）は資料の下
  - イメージ映像：3Dの場面を縦のカメラで書き出し直す。いまの `Stage` は 1280x720 決め打ちで、縦にすると下半分が黒くなる（試した）。
    場面ごとに縦のカメラの角度を足す
  - 文字カード：縦の配置を作る
- 字幕の帯：画面の高さの約6割（中心 y=1180）。1行13字まで、2行まで。白の太いゴシック（Noto Sans JP Black）に黒いフチ8px。
  数字と要の語（13年、17人、FBI など）を黄色に。区切りは文節で、声の文字ごとの時刻（`build/tts_cache` の alignment）に合わせて替える
- 隠れやすい所（第三者の目安。数字は調べた先で違う）：上 180〜290px、下 380〜670px、右 120〜190px。字幕と大事な文字は x 60〜930、y 290〜1250 に入れる

## 根拠（調べた範囲）

- 字幕：100本以上の研究で、字幕は理解・注意・記憶を上げる（Gernsbacher 2015 のまとめ。自己申告の研究が多いという批判もある）。
  Facebook の社内調査で視聴時間が平均12%（3Play Media の紹介）。「1語ずつ光らせると20%伸びる」の類いは、作り方の分からない業者の数字
- 縦型は音ありで見られる前提：TikTok の利用者の88%が「音は欠かせない」（Kantar）。字幕は音の代わりではなく、理解の助け
- 日本語の字幕の速さ：視線計測で1秒6字までは負担が変わらず、8字で重くなる（豊倉・山田 2017）。この回の声は1秒約5字
- ショートの入口の数字は「視聴された（スワイプされなかった）」の割合。最初の1秒で何を見せるかが効く
